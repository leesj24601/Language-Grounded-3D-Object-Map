# Notion 실험 차트 선택 강조 및 설명 정리 설계

## 목표

Notion 포트폴리오의 실험 결과 차트에서 최종 선택 설정을 즉시 식별할 수 있게 하고, 차트와 본문 사이에서 반복되는 설명을 줄인다.

## 차트 디자인

- 세 차트 모두 선택한 x축 범주 전체를 연한 금색 배경 사각형으로 감싼다.
- 강조 영역에는 금색 테두리를 함께 적용해 색상만으로 상태를 구분하지 않게 한다.
- 강조 영역 상단에 `SELECTED` 배지를 배치한다.
- 기존의 작은 `최종 선택` 또는 `선택값` 주석은 제거한다.
- Precision, Recall, Duplicate rate의 색상·해칭·직접 수치 라벨은 유지한다.
- y축은 모든 차트에서 0–112%로 유지해 비교 기준을 바꾸지 않는다.

## Notion 설명 정리

- 차트 내부 subtitle과 중복되는 차트별 이탤릭 캡션 3개를 제거한다.
- 공통 평가 기준과 원본 metrics 링크를 한 줄로 합친다.
- 결과 요약은 다음 세 항목만 남긴다.
  1. 최종 선택 설정과 대표 수치
  2. threshold 0.35 및 association distance 0.6m 선택 이유
  3. Frames와 min observations가 함께 변한 비교라는 해석상 주의점
- 상세 수치와 실험별 해석 토글은 그대로 유지한다.

## 데이터 및 검증

- 기존 metrics JSON을 다시 읽어 차트를 생성한다.
- 기존 기대값 검증을 유지해 수치 변경이나 잘못된 파일 연결을 탐지한다.
- PNG로 시각 검수한 뒤 SVG를 Notion에 업로드한다.
- 최종 Notion 재조회에서 새 차트 3개, 축약된 결과 요약, 상세 수치 토글, 원본 metrics 링크가 존재하는지 확인한다.
